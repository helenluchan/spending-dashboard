# Helen's Spend Dashboard

A personal finance dashboard visualizing 30 days of credit card spending. Built as a way to play around and get experience with Claude Code.

## Built with

- Python + Streamlit for the web framework
- pandas for data processing
- Plotly for interactive charts

Transaction data is exported from my credit card statement and hosted as a CSV on a private GitHub Gist — the dashboard fetches it live on every load. Deployed on Streamlit Community Cloud.

Vibe-coded with Claude.
